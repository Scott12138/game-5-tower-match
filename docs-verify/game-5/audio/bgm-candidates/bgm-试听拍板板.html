打包体积：这条得一起拍

PACKAGING

一首完整 BGM 是 2~4 MB，而主玩页所在的主包现在已经 2.99 MB / 4 MB 红线。 所以"选哪首"之外，还得选"怎么装"。三条路各有代价，我列出来等你一起拍：

① 裁成 30~45 秒无缝循环

把选中的曲子做成一个可循环的短句，压到 96 kbps 单声道。

体积 ≈ 400~550 KB，可以直接放进 game 分包。

代价：听久了会察觉重复（但休闲消除类游戏这是行业常规做法）。

② 整曲放进 game 分包

分包不占主包那 4 MB 红线，首屏不受影响。

代价：玩家第一次进主玩页才把这 2~4 MB 下下来，进关前会多等一下。

③ 整曲放远程 CDN

包体零负担，随时可换曲、可加第二首。

代价：要额外搭一处静态托管，且首局要等网络；离线场景需自己做缓存兜底。
