## 四、一键重取（示例）

```bash
cd game-5-cocos
mkdir -p tools/_bgm/raw && cd tools/_bgm/raw
curl -sSL -o pt-folk-chinese.mp3 \
  "https://peritune.com/music/PerituneMaterial_Folk_Chinese.mp3"
curl -sSL -o pt-folk-chinese-loop.zip \
  "https://peritune.com/loop/PerituneMaterial_Folk_Chinese_loop.zip"
```
（T-STATION 的音乐分发在 `tnosite.com/wp-content/uploads/` 下，路径见上表；
逐条下载脚本见第 43 轮的工具调用记录。）
