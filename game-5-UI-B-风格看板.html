浅色留白 玉质厚牌 青玉主色 朱红 ≤3% 面积

V1配色 token

全作唯一色彩来源，代码里禁止出现魔法色值。彩色极省：只有青玉（主）/ 暖金（点缀）/ 朱红（告警 + 🀄️）三种，其余全是白与墨。 game-4 首页「白板感」的根因之一就是朱红边框面积太大 —— B 案把朱红面积压到 ≤ 3%。

V2玉质厚牌（核心资产）

牌不是「贴纸」是「玉牌」：靠厚度 + 圆角 + 柔光影做体积，不靠纹理贴图（这也是 B 案美术产能低于宣纸风的原因）。 牌底不用纯白 —— 纯白会「飘」，用自上而下 #FFFFFF → #F4EFE6 的极淡渐变。

V3UI 组件

槽位 = 信息区必须齐；按钮 = 青玉实心胶囊；道具格热区 56pt 达标。告警不用红字吓人，用「颜色 + 抖动 + 心跳音」三通道。

V5六页视觉形态

灰模示意，只表达「元素位置与留白比例」，不表达最终细节。留白比例：①≈70% ②≈60% ③≈75% ④≈35%（信息密度最高） ⑤弹层内≈45% ⑥≈50%。

V3栅格与关键尺寸

设计稿 750×1334（@2x）、8pt 栅格（=16px）、逻辑宽 375pt。所有主内容对齐到左右 40px 安全线。
